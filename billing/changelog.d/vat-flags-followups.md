### Changed

- **The VAT register counts Nepal VAT only, and starts with the mode.** The VAT column and the "Return figures" sum the tax levels flagged as Nepal VAT. Another tax (India GST, a foreign sales tax) is no longer counted as VAT, and a document whose only tax is another tax shows its whole value as exempt sales. Only documents dated on or after the mode's start day are listed, earlier months are not offered, and with the mode never switched on the register lists nothing and says so. A document that carries tax but was never classified (no flags) is listed with blank amounts, left out of every total and counted in a warning above the table; run `php artisan billing:fiscal-vat-split` to classify invoices.
- **Credit and debit notes copy their invoice's Nepal VAT flags** when issued (two new nullable columns on `tax_notes`, expand only). Notes can now be issued only while Nepal VAT mode is in effect (on, and its start day reached) and never on a taxed invoice that was never classified: the note panel disables the actions with the reason, and the service refuses with a message that names the command. A note's flags never change after it is issued, so none is ever written without them.
- The notes panel and the note actions open only when Nepal VAT mode is in effect, and the refusal names the start day when the mode is on but has not started.
