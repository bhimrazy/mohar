title: Khalti

import { Steps } from '@astrojs/starlight/components';

Clients are sent to Khalti's payment page, then come back to the invoice. The app looks the payment up at Khalti
before it marks the invoice paid. Khalti charges in Nepalese rupees (NPR).

You need a Khalti merchant account.

<Steps>

1. In the Khalti merchant dashboard (`admin.khalti.com`), open **Keys** and copy the live secret key. For testing,
   use the key from the test dashboard (`test-admin.khalti.com`).

2. Go to **Setup → Gateways → Khalti** and paste the **Secret key**. Keep **Sandbox mode** on while you use the
   test key.

3. If your invoices are in another currency, set **Charge in currency** to Nepalese rupee.

4. Select **Save gateway**, then **Test connection**. No money moves.

5. Turn on **Active** and save.

6. To go live, turn **Sandbox mode** off, paste the live secret key, save and test again.

</Steps>

Refunds go through Khalti from the transaction on the invoice.
