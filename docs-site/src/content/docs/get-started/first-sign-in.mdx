<Steps>

1. Open your address followed by `/login`, for example `https://billing.example.com/login`.

2. Sign in with the administrator email and password you chose during install. If the installer printed a one-time
   password, you are asked to choose a new one now.

3. Set up two-factor authentication with an authenticator app. Staff must do this before they can use the admin
   area; you can change that rule later under **Setup → Settings → Security**.

4. You land on the dashboard. Its **Needs attention** list and **System health** panel show what to fix first, such
   as a scheduler that has not run yet.

    <Screenshot name="dashboard" alt="The dashboard after sign-in, with totals, a list of items that need attention and the navigation on the left." />

</Steps>
