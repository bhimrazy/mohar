# Owner requirements and decisions

Distilled from the owner's messages in the build session of 2026-10-17 and 2026-10-18 (times UTC). Each line gives
the requirement in plain English, the date it was set, where it is implemented or specified, and its status as
verified against the repository on 2026-10-18. Paths are relative to the repository root.

Status values: **Done** (merged on `develop`), **In progress** (work exists in a branch or worktree), **Specified**
(a spec or ADR exists, no code), **Not started** (no spec and no code), **Ongoing** (a standing practice).
