## Summary

The kernel added five things today: the company clock, the report registry, TLD attributes, order linking and
`ReturnHint::$signedPaid`. Each one is sound, and none breaks a module boundary. Parallel work is now slowed by
shared files, not by the design:

- every open PR edits `changelog.md`;
- three ADRs are edited as running logs (ADR 0009's amendment numbers, ADR 0021 §3, the ADR 0024 §10 table);
- three central maps sit in one module's files (`WebhookEventTypes::MAP`, the clock-scan baseline, Domains'
  `RegistrarGateway`).

Seven small kernel changes, made first by the CTO session, let about twelve module packages run in three waves with
at most two touching the same module at once.
