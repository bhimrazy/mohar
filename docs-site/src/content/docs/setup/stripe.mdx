Clients pay on Stripe's hosted Checkout page. Card details never reach your server. Stripe tells the app about each
payment through a webhook, and the app looks the payment up at Stripe before it marks the invoice paid.

You need a Stripe account. On your live install, use live keys: test mode works only on a copy of the app that is
not running in production (see [test mode and production](../payment-gateways/#settings-every-gateway-has)).

<Steps>

1. Go to **Setup → Gateways → Stripe**. Copy the address shown under **Webhook** at the bottom of the page. It ends in
   `/billing/webhooks/stripe`.

2. In the Stripe Dashboard, open **Workbench → API keys** and copy the secret key. You can use a restricted key
   instead; it needs write access to Checkout Sessions and Refunds, and read access to PaymentIntents, Refunds and
   Disputes.

3. In Stripe Workbench, create a **snapshot** event destination for the webhook address from step 1, with these
   events:
    - `checkout.session.completed`
    - `checkout.session.async_payment_succeeded`
    - `checkout.session.async_payment_failed`
    - `checkout.session.expired`
    - `payment_intent.succeeded`
    - `refund.created`
    - `refund.updated`
    - `charge.dispute.created`

    Copy the destination's signing secret. It starts with `whsec_`.

4. Back on the gateway page, turn **Test mode** off (leave it on only on a staging copy with test keys), then paste
   the **Secret key** and the **Webhook signing secret**. The **Publishable key** is optional.

    <Screenshot name="gateway-stripe" alt="Stripe gateway settings: general options, test mode, secret key, webhook signing secret, publishable key, test connection and the webhook address." />

5. Select **Save gateway**, then **Test connection**. A passing test shows your Stripe account name; nothing is
   created at Stripe.

6. Turn on **Active** and save. Pay a small invoice to check the whole flow, then refund it.

</Steps>

Stripe keeps test and live data apart: a live webhook destination has its own signing secret, so create one in live
mode for the live install.

<Aside>
	Refunds, full or partial, are sent to Stripe from the transaction on the invoice. A refund made in the Stripe
	Dashboard is recorded too, through the webhook.
</Aside>
