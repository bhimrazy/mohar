## 4. Process

**Gates that earn their cost**: the combined review (every blocker today came from it); probes adopted as tests
(re-checks take 10 to 20 min); the re-reviewer on security PRs (caught the fix-induced defects in #252, #253, #294);
the architect on the kernel (#262 to #265, #294's changelog drift); CTO diff verification of small follow-ups (#295,
#297, #301, each under an hour).

**Gates that cost more than they return**: step 7's "merge `origin/develop`" on every PR (about 42 runs a day, most
only because of the changelog; PR CI already tests the merge ref, and what is missing is a build of `develop`, §3);
unbounded fix rounds on one file (seven on #252 cost more than designing the scanner once).

**Written rules that do not match practice**:

- **Agent budget.** `operating-model.md:80` says "five to seven agents, periodic reviews included"; the owner's
  standing rule is **at most 5 at once**, more only with approval. A four-advisor round leaves one slot.
- **CI on `develop`.** `operating-model.md:113` says CI runs on pushes to `develop`; `ci.yml:20` does not.
- **Stale setup.** "Two build sites" (`operating-model.md:156`) still describes two codespaces. `state.md` (10:30 UTC)
  misses 15 merges and lists #242 and #262 to #265 as open. "Cleanup every 30 minutes": 18 of 26 worktrees are merged.
- **#300** (a `Migration` model and key-rotation change) merged with no review, CTO-verified from the diff, against
  the "Money, auth, permissions, migrations" row. Reasonable (a reviewed #253 item, probe failing first), but unwritten.
- **Incidents in prose only**: an agent ran `npx vite` from the registry despite the lockfile rule; a browser check
  downloaded into the owner's Chrome instead of Playwright; agents overwrote each other's files in the shared
  scratchpad. None is in `history.md` or `operating-model.md`, and none is enforced by `.claude/settings.json`.

**The CTO session's calls.** Sound: the macOS move (#271) in a day; registrar C1 to C3 stacked with the architect on
each PR; open questions decided in the PR before each re-check (#252 round 7, #286 size cap); follow-ups to issues,
not rounds (#305, #307, #309, #311); the cooldown on #242 held. Poor: a seventh fix round on #252 instead of a stop
and redesign after round 3; #278 classed Low; two KYC PRs (#286, #312) in parallel on one image pipeline; the
`develop` build off for two days; nine PRs opened in 37 minutes after the stall; `state.md` not updated all afternoon.

## 6. Recommendations (ranked)

1. **Build `develop` again** (small, DevOps). Restore `push: branches: [develop]` in `ci.yml` while public (free,
   about 9 min a merge); one dispatch per batch when private. Then drop step 7's mandatory develop merge when the PR
   has no conflict and its CI ran on a merge ref under 3 merges old. Effect: semantic conflicts caught within one
   merge; about 15 fewer CI runs a day.
2. **Changelog fragments, owner decision today** (small). One file per PR in `billing/changelog.d/<pr>.md`,
   assembled at release; `vp check` covers the folder. Effect: no changelog conflict, about 25 to 30 fewer runs a
   day, no second sign-offs, no hand-merge format failures (#252, #282).
3. **Cap fix rounds at two, then redesign** (medium). After a second re-review finds a fix-induced defect, the PR
   stops; the architect writes invariant, input space and budget first (Redactor: ADR 0023 "Log redaction rules"),
   then a generated-corpus differential test against a slow reference masker with time and memory budgets replaces
   the 11 probe files (#311). A confirmed secret leak is never Low. Effect: 11 Redactor rounds become 2 next time.
4. **Make the three incidents mechanical** (small; owner approves the config). A `PreToolUse` deny for `npx` outside
   a lockfile allowlist (`vp`, `tsc`, `playwright`); Chrome DevTools MCP denied to subagents; a per-agent
   `$SCRATCH/<agent-slug>/` in every brief. Effect: no repeat that depends on agents remembering.
5. **Rewrite the model to match machine and owner** (small). At most 5 agents including the review round (two waves:
   CEO and CTO, then security and architecture); delete "Two build sites"; one owner per hot area so no two PRs
   change one pipeline (KYC); write the CTO-verified follow-up rule (#300). Effect: `resume-session` restarts right.
6. **Hourly hygiene** (trivial). `storage-cleanup.sh --apply` (18 worktrees, about 7 GB); `state.md` after every
   merge batch; record any stall over 30 minutes and its cause.
7. **Flaky and hollow tests** (small). Fix #310 (freeze time) and #209 (serialise) or quarantine the same day; every
   new guard test or probe shows fail-first evidence in the PR body. Effect: no more #275, #277, #292.
